# Yapı kartı: Nimes

Hedef: **sağlam dönem**, Roma İmparatorluğu ("Ville Romaine") — Maison Carrée, Arena, Tapınağı.
Etiketler: **[K]** kaynak · **[F]** bugünkü yapı / fotoğraf · **[T]** tahmin.

## 1. Kimlik [K]
- Kent: Nîmes, Gallia Narbonensis; Roma'nın güneydoğusundaki en önemli Roma kenti.
- Maison Carrée: MS 19'da Lucius Aemilius Lepidus tarafından yaptırılan, Roma akropolisine ev sahipliği yapan dik üçgen tapınak.
- Arena: MS 90'larda Titus tarafından inşa edilen, bugün hâlâ spor salonu olarak kullanılan büyük Roma arenası.
- Tapınağı Augustus: MS 19'da Augustus tarafından inşa edilen tapınak.
